Tasky: private android app, public apk release

Android habit-challenge tracker (Kotlin / Jetpack Compose). Source, tests, and the upload keystore stay in a private repo. On every push to main, GitHub Actions bumps MAJOR.MINOR.PATCH.BUILD in version.properties (regular builds increment the last digit; past .99 it carries left), runs unit tests, builds a signed release apk, syncs the private public/ folder into navforu/tasky-app with a fine-grained token, and publishes the apk as a release on that public repo. GitHub Pages hosts the product showcase with screenshots and use cases. Live product page: https://navforu.github.io/tasky-app/. No account, server, analytics, or ads — challenge data stays on the device.
