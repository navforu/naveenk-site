JoyCart: private android app, public apk release

Pretend Android shop (Kotlin / Jetpack Compose). Share an Amazon or Flipkart product link, tap Buy Now, and enjoy a fake checkout — nothing is charged or shipped. Source and tests stay in a private repo. On every push to main, GitHub Actions bumps MAJOR.MINOR.PATCH.BUILD in version.properties, runs unit tests, builds a release apk, syncs the private public/ folder into navforu/joycart-app, and publishes the apk as a release on that public repo. GitHub Pages hosts the product showcase with screenshots. Live product page: https://navforu.github.io/joycart-app/. Pretend cards persist on-device; cart and orders are in-memory only.
