Mistfront

Static website for Mistfront, a weekend retreat in the foothills of the Western Ghats. It showcases the A-frame cabin, villa, and pool with an auto-generated photo gallery and an enquiry form that emails the owners. Deployed to GitHub Pages through CI that runs Node and Python test suites before every publish.
